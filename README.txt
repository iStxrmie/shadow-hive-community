THE SHADOW HIVE — WEBSITE STARTER

Files:
- index.html   Main website page
- styles.css   Dark red / black visual design
- script.js    Mobile navigation and demo terminal behaviour

To preview:
1. Open the folder.
2. Double-click index.html.
3. It should open in your web browser.

To publish:
You can upload these files to a new GitHub repository and import that repository into Vercel.
Keep secrets such as API keys and Discord bot tokens out of this website folder and out of GitHub.

The Dr. V.I.R.U.S. box is currently a visual demo only. It does not call OpenAI.
This is an unofficial fan-made Resident Evil-inspired project and is not affiliated with Capcom.
